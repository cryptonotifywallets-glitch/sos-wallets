📧 Email Delivery Setup

Want notifications to actually reach an inbox? Pick a provider below. Web3Forms is the fastest — one free access key, no dashboard, works from any website or localhost. EmailJS can send directly to each recipient's address (needs 3 IDs). The app auto-falls back so a notification is never silently lost.

⚡ Quickest option — no dashboard, no domain restrictions

  1. Open app.web3forms.com/onboarding/create and enter your own email (this is where notification copies land).
  2. You instantly get an Access Key (a UUID like a1b2c3d4-…). Copy it.
  3. Paste it below + the email you used. Click Save then Send Test Email.

ℹ️ Web3Forms delivers to your verified inbox. The app sends a copy of every notification there (with the recipient's address + message embedded) so you can forward it. To send directly to recipients with zero forwarding, use EmailJS instead (or both — the app auto-falls back from EmailJS to Web3Forms).

📖 Step-by-step EmailJS setup guide (sends directly to recipients)

🔒 Keep your personal email private

The "From" address recipients see is whatever email you connect as an EmailJS Service. Create a dedicated sender email (e.g. soswallets.notify@gmail.com) or use a custom domain for full branding.

📋 Walkthrough

  1. Create a free account at dashboard.emailjs.com/sign-up (200 emails/month free).
  2. Email Services → Add New Service → choose Gmail → sign in with your dedicated sender email → copy the Service ID (service_xxx).
  3. Email Templates → Create New Template → set To Email: {{to_email}}, From Name: {{from_name}}, Subject: {{subject}}, Content (HTML toggle): {{html}} → save → copy Template ID (template_xxx).
  4. Account → API Keys → copy your Public Key.
  5. ⚠️ Important: Account → Security → if "Allowed Domains" is on, add this site's origin () or enable "Allow API access outside browser". Otherwise EmailJS returns 403.
  6. Paste all three IDs below → Save → Send Test Email.

📋 Copy-paste EmailJS template (fixes "email received but no content")

If your emails arrive but show {subject} or blank content, your template has the wrong placeholders. EmailJS needs double curly braces {{variable}} — not single braces. Paste this exactly into your EmailJS template's Content field (make sure the HTML toggle is ON):

Subject: {{subject}}

<div style="font-family:Arial,sans-serif;max-width:600px;margin:0 auto;padding:20px;">
  <h2 style="color:#4f7fff;">{{subject}}</h2>
  <div style="font-size:15px;line-height:1.6;color:#333;">
    {{{message}}}
  </div>
  <hr style="border:none;border-top:1px solid #eee;margin:20px 0;">
  <p style="font-size:12px;color:#999;">Sent from SOS WALLETS v3</p>
</div>

Template settings: To Email = {{to_email}}, From Name = {{from_name}}, Subject = {{subject}}, Reply To = {{to_email}}. Use {{{message}}} (triple braces) in the content body so HTML renders properly.

Set up automatic, recurring email notifications that fire on a timer while the app is open — daily portfolio summaries, weekly transaction digests, payment reminders, or custom recurring alerts.
